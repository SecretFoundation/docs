# 👓 Viewing Agentic Settings after deployment

After the VM is created, open the VM and navigate to Agentic Settings.

This page shows:

* registration network
* transaction
* agent ID
* agent metadata
* image
* x402 support status
* supported trust models
* registered services and endpoints
* Link to the agent's page on 8004scan.io&#x20;
* Link to the agent's he registration transaction on the target thange

This gives you a single place to inspect the VM’s ERC-8004 identity and the service metadata published for it.
