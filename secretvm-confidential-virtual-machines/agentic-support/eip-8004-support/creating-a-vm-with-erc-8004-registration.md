# ✨ Creating a VM with ERC-8004 registration

During VM creation:

1. Open Agentic Settings
2. Enable Register on ERC-8004

<figure><img src="../../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>

3. Fill in the agent metadata:

* Agent name
* Image URL
* Description

<figure><img src="../../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

4. Review the default services:

* teequote
* workload

5. Optionally add more services
6. Optionally enable:
   * x402 support
   * Additional trust models such as:
     * Reputation
     * Crypto-economic
     * TEE attestation
7. Select the target registration chain
8. Create the VM

After the VM is successfully created, SecretVM registers the agent and stores the resulting registration details in the VM’s Agentic Settings view
