# ✅ Verifying a SecretVM

Verifying a Confidential Virtual Machine involves retrieving its Attestation Quote, parsing it and verifying that the quote is authentic, and that the values of attestation report registers match the expected values.

We decribe two ways for the attestation - [Full Verification](full-verification.md) (a very technically involved process), and [Quick Verification](quick-verification.md) that allows less technical users to validate authenticity of the workloads running on a given SecretVM&#x20;
