# Setting up the Secretd-sgx-Proxy

`secretd-sgx-proxy` is a gRPC transparent proxy sidecar for Secret Network SGX nodes. It gates access to sgx data endpoints (traces, enclave records) behind a block-based consumption billing model

The detailed instructions on the installation and peration of the Secred-sgx-proxy are available on Github here: [https://github.com/scrtlabs/secretd-sgx-proxy](https://github.com/scrtlabs/secretd-sgx-proxy)
