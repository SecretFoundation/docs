# v1.21.6 TESTNET PATCH

## Secret Network v1.21.6 Patch Instructions <a href="#secret-network-v1-21-upgrade-instructions" id="secret-network-v1-21-6-patch-instructions"></a>

### 1. Stop the current node
```bash
sudo systemctl stop secret-node
```

### 2. Prepare for migration
```bash
# Remove migration files that could be left from previous migrations
rm -f /opt/secret/.sgx_secrets/migration_*

# Optional: get self target info. By such we'll rely on local attesattion rather than on remote during the migration
secretd migrate_op 5
```

### 3. Get the v1.21.6 binaries

This is the release page for testnet: [https://github.com/scrtlabs/SecretNetwork/releases/tag/v1.21.6](https://github.com/scrtlabs/SecretNetwork/releases/tag/v1.21.6)

```bash
wget https://github.com/scrtlabs/SecretNetwork/releases/download/v1.21.6/secretnetwork_1.21.6_testnet_goleveldb_amd64_ubuntu-22.04.deb
wget https://github.com/scrtlabs/SecretNetwork/releases/download/v1.21.6/check_hw_1.21.6_ubuntu-22.04.tar.gz
```


```bash
# Restart the node
sudo systemctl restart secret-node
```
