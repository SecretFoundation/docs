# v1.21 TESTNET

## Secret Network v1.21 Instructions <a href="#secret-network-v1-21-upgrade-instructions" id="secret-network-v1-21-upgrade-instructions"></a>

### ⚠️ IMPORTANT NOTES ⚠️ <a href="#important-notes" id="important-notes"></a>

* All coordination efforts will be done in the "SN Validators" Telegram group.
* Make sure to [backup your validator](../maintaining-a-node-validator/validator-backup.md) before making any changes.
* **Please read carefully before you begin the upgrade.**

### ⚠️ Cosmovisor tool may NOT be used with this upgrade. This is due to the following facts:
* After the installation, the secret node should perform an additional step, BEFORE the actual network upgrade (more on this later).
  

### 1. Wait till the upgrade height is reached
When the network reaches the halt height, you'll see this message in your node's log (`journalctl -fu secret-node`):

```bash
2:00PM ERR UPGRADE "v1.21" NEEDED at height: ...
2:00PM ERR CONSENSUS FAILURE!!! err="UPGRADE \"v1.21\" NEEDED at height: ...
```

### 2. Stop the current node
```bash
sudo systemctl stop secret-node
```

### 3. Prepare for migration
```bash
# Remove migration files that could be left from previous migrations
rm -f /opt/secret/.sgx_secrets/migration_*

# Optional: get self target info. By such we'll rely on local attesattion rather than on remote during the migration
secretd migrate_op 5
```

### 4. Get the v1.21.6 binaries


### 5. Perform the Secrets handover procedure

```bash

# extract check-hw tool
tar -xzvf check_hw_1.21.6_nowl_logging.gz
cd check-hw

# produce self migration report
./check-hw --testnet --migrate_op 1

# export sealed data based on the migration report
secretd migrate_op 2

# next ver: import sealed data
./check-hw --testnet --migrate_op 3

cd ..
```

### 6. Install the v1.21.6

```bash
sudo dpkg -i secretnetwork_1.21.6-3-g5d8e02a11_testnet_nowl.deb"
```

### 7. Perform seed rotation

```bash
secretd migrate_op 1
response=$(curl -X POST --data-binary @/opt/secret/.sgx_secrets/migration_report_remote.bin http://51.8.118.178:3000/)

echo "$response" | jq -r '.buf1' | base64 -d >/opt/secret/.sgx_secrets/migration_report_remote.bin
echo "$response" | jq -r '.buf2' | base64 -d >/opt/secret/.sgx_secrets/rot_seed_encr.bin

secretd migrate_op 8
secretd migrate_op 9
```

### 8. Finally start the node
```bash
# re-apply any systemd unit file customizations

# Restart the node
sudo systemctl restart secret-node
```

After restarting the node with v1.21.6, you should see `INF applying upgrade "v1.21" at height: ...` in the logs (`journalctl -fu secret-node`). Once 67% of voting power comes online, you'll see blocks executing again.

## In Case of an Upgrade Failure <a href="#in-case-of-an-upgrade-failure" id="in-case-of-an-upgrade-failure"></a>

In the event of an issue at upgrade time, we should coordinate via the "SN Validators" Telegram group.
